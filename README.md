# Meowdoku Guide Static Website

Files:
- index.html
- style.css
- script.js
- assets/

Open index.html directly in a browser, or deploy the folder to GitHub Pages.
No build step or package installation is required.

Google AdSense site code is installed in index.html <head> using publisher ID ca-pub-6307656880368693. Since this project uses client-side page routing, the shared document head applies to every in-site view.
